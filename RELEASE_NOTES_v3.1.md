# HypeTek Server Launcher v3.1

First public GitHub release of the WPF-based HypeTek Server Launcher.

## Highlights

- Portable Windows 10/11 launcher, no installation required
- Custom server labels and addresses, including custom ports
- Multiple entries for the same host with different ports
- Individual server button colors
- German, English and Russian interface
- Full-window custom background images
- BMP, PNG, JPG/JPEG, GIF and TIFF support
- Fill, Fit and Stretch background modes
- Adjustable background dimming
- Dynamic tile layout with scrolling for larger server lists
- Improved Windows DPI/display-scaling compatibility

## Start

Extract the ZIP and run `Start_ServerLauncher.vbs`.

Use `Start_ServerLauncher.bat` for troubleshooting.

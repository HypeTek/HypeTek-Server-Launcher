# HypeTek Server Launcher v3.5

## New

- Compact **icon dropdown** in the server add/edit dialog.
- Manual symbols: **Server, PC, Laptop, Website, NAS, Router, Raspberry Pi, VM and Generic**.
- **Automatic** icon selection remains available.
- The icon selector is deliberately kept small beside the button-color controls.
- Existing icon choices from v3.4.x are migrated/understood automatically.

## Existing features

- Drag & Drop server ordering
- Windows 10/11, portable and no admin rights required
- Safe per-user configuration under LocalAppData when installed in Program Files
- Custom labels, addresses and ports
- Same host with different ports
- Per-server and default button colors
- BMP, PNG, JPG/JPEG, GIF and TIFF backgrounds
- German, English and Russian

## Upgrade from v3.4.2

No configuration conversion is required. When the launcher runs from a protected program folder, the existing data in `%LOCALAPPDATA%\HypeTek\ServerLauncher` continues to be used.
